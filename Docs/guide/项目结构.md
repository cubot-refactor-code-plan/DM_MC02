# 项目结构

## 顶层结构

按字母排序的一层结构：

```txt
.git/                    版本库
.settings/               STM32CubeIDE 工程设置
.vscode/                 VS Code 任务、调试与编辑器参数
build/                   编译产物（不入库）
cmake/                   工具链文件与 CubeMX 的 CMake 集成
Core/                    HAL 初始化与中断服务
Docs/                    开发文档、硬件图纸、器件手册
Drivers/                 STM32 HAL 与 CMSIS
Flash/                   烧写脚本、SVD、udev 规则
Middlewares/             FreeRTOS、ST USB Device
User/                    业务代码，按分层组织
Example/                 参考代码与阅读笔记；can_backup/ 为旧 CAN 链路的归档
.clangd                  clangd 语言服务器参数
.clang-format            clang-format 格式化规则
.gitattributes           行尾与二进制文件的 git 属性
.gitignore               忽略规则
CMakeLists.txt           主构建脚本
CMakePresets.json        构建预设
DM_MC02.ioc              CubeMX 工程文件
README.md                工程介绍
startup_stm32h723xx.s    启动文件
STM32H723XG_FLASH.ld     链接脚本（构建实际使用，含 .dma_buffer 段）
STM32H723xG_flash.ld     另一份 CubeMX 生成的链接脚本，未参与当前构建
```

## 维护归属

先分清哪些内容由本工程维护、哪些由 CubeMX 或上游生成，再动手：生成物手改后会在重新生成时丢失。

| 条目 | 归属 | 说明 |
| --- | --- | --- |
| `Core/` | CubeMX 生成 | 只在 `/* USER CODE BEGIN */` ~ `/* USER CODE END */` 段内写代码 |
| `cmake/stm32cubemx/` | CubeMX 生成 | HAL / FreeRTOS 的源文件列表 |
| `startup_stm32h723xx.s` | CubeMX 生成 | 启动文件 |
| `Drivers/` | ST 提供 | STM32 HAL 与 CMSIS |
| `Middlewares/` | ST 提供 | FreeRTOS、USB Device 协议栈 |
| `User/` | 本工程维护 | 全部业务代码，见下节 |
| `DM_MC02.ioc` | 本工程维护 | 外设配置的唯一来源，改外设时用 CubeMX 改这一个文件 |
| `CMakeLists.txt`、`CMakePresets.json` | 本工程维护 | CubeMX 只生成一次，之后自行维护；见 [../build/构建系统改动.md](../build/构建系统改动.md) |
| `STM32H723XG_FLASH.ld` | 本工程维护 | 构建实际使用的链接脚本，本项目加了 `.dma_buffer` 段；见 [../build/链接脚本改动.md](../build/链接脚本改动.md) |
| `Flash/` | 本工程维护 | 烧写脚本、SVD、udev 规则与调试配置 |
| `Example/` | 本工程维护 | 参考代码与阅读笔记；`can_backup/` 归档旧的 CanBus 链路 |
| `Docs/`、`README.md` | 本工程维护 | 文档 |
| `.clang-format`、`.clangd`、`.vscode/` | 本工程维护 | 编辑器与工具配置 |
| `build/`、`.settings/` | 生成产物 | 不入库 |

## User 层

```txt
User/
├─ CMakeLists.txt         GLOB_RECURSE 收集 User/**/*.{c,cpp}，新增文件无需改构建脚本
├─ Bsp/              板载支持包：只依赖 HAL，不认识上层
│  ├─ bsp_can             FDCAN×3：Message Buffer 收发、Bus-Off 恢复、诊断计数
│  ├─ bsp_uart            UART 模板驱动：IDLE+DMA 接收、流缓冲区、收发恢复
│  ├─ bsp_dwt             内核 CYCCNT 计时
│  ├─ bsp_pwm             PWM 通道：占空比 / 脉宽 / 频率（舵机、陀螺仪、蜂鸣器）
│  ├─ bsp_key             按键轮询消抖
│  ├─ bsp_gpio            GPIO 输出封装（仅头文件）
│  └─ bsp_cfg             全局实例与 bsp_init()
├─ Service/          跨设备公共服务
│  ├─ service_cfg         全局实例（sys_state）与 service_init()
│  ├─ status              统一状态码 Status 与事件状态 EventState（FreeRTOS 原生 EventGroup）
│  ├─ online_check        在线检查（离线阈值为毫秒语义）
│  └─ motor_definition    电机通用运动学数据
├─ Device/           设备驱动层
│  ├─ dji_motor_group     一条总线上的 DJI 电机组（M3508 / M2006 / GM6020）
│  ├─ device_buzzer       蜂鸣器（基于 BspPwm：音调 / 音量 / 鸣叫时长）
│  └─ device_cfg          设备实例（蜂鸣器 + CAN3 电机组）与 device_init()
├─ Module/           模块层（当前为空）
├─ Protocol/         协议层（目录已预留，当前为空）
├─ Algorithm/        算法层
│  └─ pid                 PID
└─ App/              应用层
   ├─ api_main            C/C++ 转接：all_init() 与 StartDefaultTask()
   ├─ app_task.hpp        业务任务声明
   ├─ app_test.hpp        测试开关宏与测试任务声明
   ├─ task/               sys_task（10 ms：CAN / UART 补救巡检 + Online 计时）、key_task（200 ms 轮询按键，蜂鸣器提示）
   └─ test/               can（can3_device_test / can_recovery_test）/ dwt / online_check
```

## 分层与依赖

```txt
App → Module → Device → Bsp
```

上层可以使用下层，禁止反向依赖；`Service` 是跨设备公共设施，供各层使用；`Protocol` 目录已预留（当前为空）。分层原则见 [../spec/分层架构.md](../spec/分层架构.md)。

## 命名约定

文件名全小写加下划线。详见 [../spec/编码规范.md](../spec/编码规范.md)。
