# 项目结构

## 顶层结构

按字母排序的一层结构：

```txt
.git/                    版本库
.settings/               STM32CubeIDE 工程设置
.vscode/                 VS Code 任务、调试与编辑器参数
build/                   编译产物（不入库）
cmake/                   工具链文件与 CubeMX 的 CMake 集成
Core/                    HAL 初始化与中断服务
Docs/                    开发文档、硬件图纸、器件手册
Drivers/                 STM32 HAL 与 CMSIS
Flash/                   烧写脚本、SVD、udev 规则
Middlewares/             FreeRTOS、ST USB Device
QSPI_Flash/              板载 W25Q64JV 驱动与 XIP 运行
tinyusb-0.20.0/          TinyUSB 源码
User/                    业务代码，按分层组织
.clangd                  clangd 语言服务器参数
.clang-format            clang-format 格式化规则
.gitattributes           行尾与二进制文件的 git 属性
.gitignore               忽略规则
CMakeLists.txt           主构建脚本
CMakePresets.json        构建预设
DM_MC02.ioc              CubeMX 工程文件
Doxyfile                 Doxygen 配置
README.md                工程介绍
startup_stm32h723xx.s    启动文件
STM32H723xG_flash.ld     链接脚本
```

## 维护归属

先分清哪些内容由本工程维护、哪些由 CubeMX 或上游生成，再动手：生成物手改后会在重新生成时丢失。

| 条目 | 归属 | 说明 |
| --- | --- | --- |
| `Core/` | CubeMX 生成 | 只在 `/* USER CODE BEGIN */` ~ `/* USER CODE END */` 段内写代码 |
| `cmake/stm32cubemx/` | CubeMX 生成 | HAL / FreeRTOS 的源文件列表 |
| `startup_stm32h723xx.s` | CubeMX 生成 | 启动文件 |
| `Drivers/` | ST 提供 | STM32 HAL 与 CMSIS |
| `Middlewares/` | ST 提供 | FreeRTOS、USB Device 协议栈 |
| `tinyusb-0.20.0/` | 上游源码 | TinyUSB |
| `User/` | 本工程维护 | 全部业务代码，见下节 |
| `DM_MC02.ioc` | 本工程维护 | 外设配置的唯一来源，改外设时用 CubeMX 改这一个文件 |
| `CMakeLists.txt`、`CMakePresets.json` | 本工程维护 | CubeMX 只生成一次，之后自行维护；见 [../build/构建系统改动.md](../build/构建系统改动.md) |
| `STM32H723xG_flash.ld` | 本工程维护 | CubeMX 生成过，本项目加了 `.dma_buffer` 段；见 [../build/链接脚本改动.md](../build/链接脚本改动.md) |
| `QSPI_Flash/`、`Flash/` | 本工程维护 | 外置 Flash 驱动与 XIP；烧写脚本、SVD、udev 规则 |
| `Docs/`、`README.md` | 本工程维护 | 文档 |
| `.clang-format`、`.clangd`、`.vscode/` | 本工程维护 | 编辑器与工具配置 |
| `build/`、`.settings/` | 生成产物 | 不入库 |

## User 层

```txt
User/
├─ CMakeLists.txt         GLOB_RECURSE 收集 User/**/*.{c,cpp}，新增文件无需改构建脚本
├─ Bsp/              板载支持包：只依赖 HAL，不认识上层
│  ├─ bsp_can             FDCAN×3：Message Buffer 收发、Bus-Off 恢复、诊断计数
│  ├─ bsp_uart            UART 模板驱动：IDLE+DMA 接收、流缓冲区、收发恢复
│  ├─ bsp_usb             TinyUSB 封装（HID / CDC）
│  ├─ bsp_dwt             内核 CYCCNT 计时
│  ├─ bsp_buzzer          无源蜂鸣器（PWM）
│  ├─ bsp_key             按键轮询消抖
│  ├─ bsp_gpio            GPIO 输出封装
│  ├─ bsp_cfg             全局实例与 bsp_init()
│  └─ tusb_config.h       TinyUSB 配置
├─ Service/          跨设备公共服务
│  ├─ can_bus             一条 CAN 总线：节点注册、按 ID 分发、槽位发送调度、回退缓冲
│  ├─ can_rx_node         接收节点（总线 + 帧类型 + ID → 回调）
│  ├─ can_tx_node         发送节点（一帧 8 字节划分为 1/2/4/8 个槽位）
│  ├─ service_cfg         全局实例（bus_can1/2/3）
│  ├─ status              统一状态码与系统状态标志
│  ├─ online_check        在线检查
│  └─ motor_definition    电机通用数据结构
├─ Device/           设备驱动层
│  ├─ dji_motor           DJI 电机（M3508 / M2006 / GM6020）
│  ├─ dm_motor            达妙电机（接口已定义，实现待补）
│  ├─ dm_imu              达妙 IMU
│  ├─ device_emmv5        EMM_V5 步进闭环
│  └─ device_cfg          设备实例与 device_init()
├─ Module/           模块层（当前为空）
├─ Protocol/         协议层
│  ├─ protocol_uart       自定义帧协议解析（帧头 / 长度 / 校验和 / 帧尾）
│  ├─ data_pack           数据打包
│  └─ protocol_cfg        协议实例与初始化
├─ Algorithm/        算法层
│  └─ pid                 PID
└─ App/              应用层
   ├─ api_main            C/C++ 转接：all_init() 与 StartDefaultTask()
   ├─ app_task.hpp        业务任务声明
   ├─ app_test.hpp        测试开关宏与测试任务声明
   ├─ task/               sys_task（1 kHz：CAN 巡检 + Online 计时）、key_task（实现已就绪，尚未接入）
   └─ test/               can / motor / dwt / uart / usb / qspi_flash / online_check
```

## 分层与依赖

```txt
App → Module → Device → Bsp
```

上层可以使用下层，禁止反向依赖；`Service` 是跨设备公共设施，供各层使用；`Protocol` 是跨设备协议层，无层间依赖。分层原则见 [../spec/分层架构.md](../spec/分层架构.md)。
