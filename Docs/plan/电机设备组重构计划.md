# 电机设备组（DjiMotorGroup）重构计划

> 范围：`User/Device/dji_motor_group.*` 新实现 + 旧 CAN 链路归档。
> 本文只写"要做什么、怎么做、怎么验证"，不含方案对比与选型论证。
> 状态：**待开发者审核**，尚未生成任何代码。

---

## 1. 目标

1. 用一个类 `DjiMotorGroup` 管理**一条 CAN 总线上的全部 DJI 电机**。
2. 该类**直接使用 `BspCan`** 收发，不经过 `CanBus` 与节点注册表。
3. 类**不创建任务**，只提供周期入口 `poll()`；任务由调用方创建。
4. 类**不做接收分发**，由开发者把帧喂进来（`update()`）。
5. 目的：能**单独测一台设备**的通讯。

## 2. 协议约束（来源：`Docs/sheet` 三份手册）

### 2.1 逐型号参数

| 型号 | 电调 | 合法 ID | 控制帧 | 指令范围 | 反馈帧 | `DATA[6]` | 默认减速比 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| M3508 | C620 | 1 ~ 8 | `0x200`(ID1-4) / `0x1FF`(ID5-8) | **±16384** | `0x200 + ID` | 电机温度 | 3591 / 187 |
| M2006 | C610 | 1 ~ 8 | `0x200`(ID1-4) / `0x1FF`(ID5-8) | **±10000** | `0x200 + ID` | **Null** | 36 |
| GM6020 | 内置 | 1 ~ 7 | **`0x1FE`**(ID1-4) / **`0x2FE`**(ID5-7) | **±16384** | `0x204 + ID` | 电机温度 | 1 |

### 2.2 反馈报文逐字节（三型号共用同一结构）

| 数据域 | 内容 |
| --- | --- |
| `DATA[0:2]` | 转子机械角度，0 ~ 8191（对应 0~360°） |
| `DATA[2:4]` | 转子转速，单位 rpm，有符号 |
| `DATA[4:6]` | 实际转矩电流，有符号原始值 |
| `DATA[6]` | M3508 / GM6020：电机温度（℃）；M2006：Null |
| `DATA[7]` | Null |

发送频率默认 1 kHz；DLC 8；标准帧。

### 2.3 两条硬规则

1. **GM6020 只用电流模式**（`0x1FE` / `0x2FE`）。
   手册要求：固件 ≥ 1.0.11.2，并在 RoboMaster Assistant 中打开电流环开关。
   不实现电压模式（`0x1FF` / `0x2FF`）；需要电压模式请自行刷固件后另做。
2. **GM6020 与 M3508/M2006 在 `0x205~0x208` 上共用反馈标识符**：
   GM6020 ID 1~4 与 C620/C610 ID 5~8 都发 `0x205~0x208`，数值完全相同，
   靠**控制帧**区分（`0x1FE` 对 `0x1FF`）。因此 11 个位置可以自由组合，
   接收侧不需要任何额外判断；混排区内两类同时存在时只是多发一条控制帧。

### 2.4 容量与分组

| 分组 | 位置 | 允许型号 | 反馈标识符 | 控制帧 |
| --- | --- | --- | --- | --- |
| A | 0 ~ 3 | M3508 / M2006 | `0x201 ~ 0x204` | `0x200` |
| B | 4 ~ 7 | M3508 / M2006 **或** GM6020 | `0x205 ~ 0x208` | `0x1FF` / `0x1FE` |
| C | 8 ~ 10 | 仅 GM6020 | `0x209 ~ 0x20B` | `0x2FE` |
| **合计** | **11** | | 无重叠 | ≤ 4 条 |

`0x2FE` 的第 4 组数据域（对应 ID 8）为 Null，不可用；GM6020 的 ID 上限本身也是 7。
无电机的位在构造时传 `nullptr`（布局见 §3.1）。

## 3. 类的形态

### 3.1 成员布局：固定 11 个位置

按**反馈标识符 `0x201 ~ 0x20B` 的顺序**传入，一位一台电机；该位没有电机就传 `nullptr`。

| 位置 | 反馈标识符 | 允许型号 | 控制帧 | 帧内槽位 | 指令范围 |
| --- | --- | --- | --- | --- | --- |
| 0 | `0x201` | M3508 / M2006 | `0x200` | 0 | ±16384 / ±10000 |
| 1 | `0x202` | M3508 / M2006 | `0x200` | 1 | 同上 |
| 2 | `0x203` | M3508 / M2006 | `0x200` | 2 | 同上 |
| 3 | `0x204` | M3508 / M2006 | `0x200` | 3 | 同上 |
| 4 | `0x205` | M3508 / M2006 / **GM6020** | `0x1FF` / `0x1FE` | 0 | 同上 / ±16384 |
| 5 | `0x206` | M3508 / M2006 / **GM6020** | `0x1FF` / `0x1FE` | 1 | 同上 / ±16384 |
| 6 | `0x207` | M3508 / M2006 / **GM6020** | `0x1FF` / `0x1FE` | 2 | 同上 / ±16384 |
| 7 | `0x208` | M3508 / M2006 / **GM6020** | `0x1FF` / `0x1FE` | 3 | 同上 / ±16384 |
| 8 | `0x209` | **仅 GM6020** | `0x2FE` | 0 | ±16384 |
| 9 | `0x20A` | **仅 GM6020** | `0x2FE` | 1 | ±16384 |
| 10 | `0x20B` | **仅 GM6020** | `0x2FE` | 2 | ±16384 |

**位置推出一切**：控制帧、帧内槽位、指令限幅、电调 ID、反馈标识符全部由位置决定，
调用方不需要自己算槽位、也不需要填 ID。

- 位置 0~3：电调 ID = 位置 + 1（`0x201` → C620/C610 ID 1 …… `0x204` → ID 4）
- 位置 4~7：放 3508/2006 时电调 ID = 位置 + 1，放 GM6020 时 ID = 位置 - 3；
  两者帧内槽位都是 `位置 - 4`，只是控制帧不同
- 位置 8~10：GM6020 ID = 位置 - 3（`0x209` → ID 5 …… `0x20B` → ID 7）

### 3.2 对外接口（无任何重载）

```cpp
/** 参与本组的电机型号 */
enum class DjiMotorModel : uint8_t
{
  M3508 = 0, ///< C620 + M3508，限幅 ±16384
  M2006,     ///< C610 + M2006，限幅 ±10000
  GM6020,    ///< GM6020 电流模式，限幅 ±16384
};
```

```cpp
class DjiMotorGroup
{
public:
  static constexpr uint32_t MOTOR_NUM = 11U; ///< 位置数量：反馈 0x201 ~ 0x20B
  static constexpr uint32_t FRAME_NUM = 4U;  ///< 控制帧条数：0x200 / 0x1FF / 0x1FE / 0x2FE

  /** 一个位置上的电机描述（该位置没有电机时传 nullptr，不需要它） */
  struct Member
  {
    DjiMotorModel model;  ///< 位置 0~3：M3508/M2006；位置 4~7：三种均可；位置 8~10：必须 GM6020
    float         ratio;  ///< 转子到输出轴的减速比；传 0 用型号默认（3591/187、36、1）
    float         offset; ///< 机械零位偏移，单位 rad
  };

  /** 组配置：按反馈标识符 0x201 ~ 0x20B 顺序传 11 位，无电机的位置传 nullptr */
  struct Config
  {
    Config(BspCan *can = nullptr,
           const Member *m0x201 = nullptr, const Member *m0x202 = nullptr,
           const Member *m0x203 = nullptr, const Member *m0x204 = nullptr,
           const Member *m0x205 = nullptr, const Member *m0x206 = nullptr,
           const Member *m0x207 = nullptr, const Member *m0x208 = nullptr,
           const Member *m0x209 = nullptr, const Member *m0x20A = nullptr,
           const Member *m0x20B = nullptr);

    BspCan       *can;               ///< 本组绑定的 CAN 总线
    const Member *member[MOTOR_NUM]; ///< 下标即位置（0 → 0x201，10 → 0x20B）；nullptr = 该位没有电机
  };

  explicit DjiMotorGroup(const Config &cfg);
  explicit DjiMotorGroup(const Config &cfg);

  Status           init(void);
  Status           update(const CanRxMsg &rx);
  Status           set_output(uint8_t index, int16_t raw);
  Status           poll(void);
  const MotorData &data(uint8_t index) const;
  bool             is_online(uint8_t index) const;
  bool             has_motor(uint8_t index) const;
};
```

调用处（只挂了 1 台 3508 在 ID 1 与 1 台 6020 在 ID 5）：

```cpp
static const DjiMotorGroup::Member m3508_1 {DjiMotorModel::M3508};
static const DjiMotorGroup::Member gm6020_5{DjiMotorModel::GM6020};

DjiMotorGroup motor_group({&bsp_can3,
                           &m3508_1, nullptr, nullptr, nullptr,   // 0x201 ~ 0x204
                           nullptr,  nullptr, nullptr, nullptr,   // 0x205 ~ 0x208
                           &gm6020_5, nullptr, nullptr});          // 0x209 ~ 0x20B
```

### 3.3 逐接口契约

| 接口 | 返回 | 说明 |
| --- | --- | --- |
| `init()` | `OK` / `BAD_ARG` / `NOT_INIT` | 校验成员表（型号与位置的匹配）并把配置折算进各位置；**幂等**。构造只保存配置 |
| `update(rx)` | `OK` / `BAD_ARG` / `NOT_INIT` | 标识符不在 `0x201~0x20B` 或该位没有电机 → `BAD_ARG`；解析成功后刷新该位在线状态 |
| `set_output(index, raw)` | `OK` / `BAD_ARG` / `NOT_INIT` | 按该位型号限幅后写入所属帧的槽位 |
| `poll()` | `OK` / `NOT_INIT` | 把四条帧当前值经 `BspCan::send()` 发出；该帧一个成员都没有时跳过。无成员不算失败 |
| `data(index)` | `const MotorData &` | 输出轴运动学数据；`index` 越界或该位无电机时返回内部静态全零对象 |
| `is_online(index)` | `bool` | 由该位最近一次有效反馈刷新；无电机时返回 `false` |
| `has_motor(index)` | `bool` | 该位是否挂了电机；越界返回 `false` |

**不做重载**：以上每个接口只有一个版本。内部不再使用互斥量（`set_output` 本来就没加锁，
而 `BspCan` 限定每条总线只有一个接收任务），因此本类约定为**单任务使用**。

### 3.4 数据与换算

| 内容 | 来源 | 说明 |
| --- | --- | --- |
| 输出轴运动学数据 | `Service/motor_definition.hpp` 的 `MotorData` | `param`（零位 / 减速比）在 `init()` 里折算；`radian_data` 每帧刷新：单圈角 / 多圈角 / 角速度 / 角加速度。换算式 (转子角 - 零位) / 减速比 直接写在 `_parse_feedback()` 里 |
| 协议原始量 | 本类内部（角度计数 / rpm / 转矩电流 / 温度） | 单圈角度、多圈累计、转速换算 |
| 在线判定 | `Service/online_check.hpp` 的 `Online` | 每成员一个；离线阈值 30 ms |

`DATA[6]` 的处理：M2006 固定填 0，M3508 / GM6020 取原值。

### 8.2 实现与本文档的三处差异

| 位置 | 本文档写的 | 实际实现 | 原因 |
| --- | --- | --- | --- |
| `update()` | `OK` / `BAD_ARG` / `NOT_INIT` | 多一个 `BUSY` | 拿不到数据锁时不阻塞收发循环 |
| `poll()` | `OK` / `NOT_INIT` | 同左，**单次发送失败不上报** | 失败可在 `BspCan::diagnostics` 的 `tx_buf_full` / `tx_dropped` 里查 |
| `DATA[6]` 温度 | §3.4 提到按型号处理 | **未使用**（不存储、不暴露） | 冻结的接口里没有暴露协议原始量的位置；需要时再加一个查询 |
