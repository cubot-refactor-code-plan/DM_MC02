# 进度与待办

## 已完成

- [x] DWT 驱动：`bsp_dwt`，内核 CYCCNT 计时，无外设、不依赖中断
- [x] UART 驱动：`bsp_uart`，8 路 IDLE + DMA 接收、流缓冲区、收发恢复
- [x] CAN 电机驱动：`dji_motor_group`（M3508 / M2006 / GM6020）
- [x] CAN3 设备接入：`device_cfg` 实例化 `gm6020`，`device_init()` 注册节点
- [x] 按键与蜂鸣器：`bsp_key`（200 ms 轮询消抖）+ `bsp_pwm` / `device_buzzer`（TIM12 CH2 / PB15），`key_task` 提示音
- [x] 代码规范落地：分区横幅、命名、`Config` 构造模式、禁用 `friend`、`User/` 统一格式化基线
- [x] 文档体系：`Docs/` 目录、根 `README.md` 与开发规范

> ⚠️ 上列 CAN 相关能力目前只验证到**编译通过**，尚未实机验证。

## 备注

- **BSP 封装边界（已定，不再讨论）**：`SPI1` / `SPI2` / `I2C1` 一律**不做** BSP 封装——这几类通讯在本工程都是阻塞用法（先建连接再等待：CS 拉高拉低、IIC 时序），直接由上层或库自行使用。
-  `OCTOSPI2` / `USART2(RS485-2)` 这两个暂未使用，目前先不去写相对应的内容
