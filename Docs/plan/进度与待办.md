# 进度与待办

## 已完成

- [x] USB-HID
- [x] QSPI-Flash
- [x] DWT 驱动
- [x] 多种电机驱动开发（DJI、DM）
- [x] CAN 总线分层合并：Bsp 只留纯硬件驱动，节点注册 / 分发 / 发送调度 / 回退缓冲移到Service 层的 CanBus，并补充 Bus-Off 自动恢复（见 [CAN分层合并计划](CAN分层合并计划.md)）
- [x] 代码规范落地：分区横幅、命名、`Config` 构造模式、禁用 `friend`、全仓统一格式化基线（`User/`、`QSPI_Flash/`）
- [x] PWM 与蜂鸣器分层：新增 `bsp_pwm`（句柄/通道/时钟/PSC/ARR 全部由 `Config` 手动传入，上电 0% 占空比），蜂鸣器语义上移到 Device 层 `device_buzzer`；`key_task` 三档提示音已实机验证

## 备注

- **BSP 封装边界（已定，不再讨论）**：`SPI1` / `SPI2` / `I2C2` / `OCTOSPI2` / `USART2(RS485-2)` 一律**不做** BSP 封装——这几类通讯在本工程都是阻塞用法（先建连接再等待：CS 拉高拉低、IIC 时序），直接由上层或库自行使用；`QSPI_Flash` 继续直接调 HAL。
  已封装：CAN×3、UART×8、GPIO、KEY、USB、DWT、PWM×6（`bsp_pwm`，参数由 CubeMX 值手动传入，上电 0% 占空比）。
- CAN 合并的实机回归（三路收发、节点回调、Bus-Off 恢复、回退缓冲溢出、Live Watch 读 `diagnostics`）尚未执行，清单见 [CAN分层合并计划](CAN分层合并计划.md)。
