# 进度与待办

## 已完成

- [x] USB-HID
- [x] QSPI-Flash
- [x] DWT 驱动
- [x] 多种电机驱动开发（DJI、DM）
- [x] CAN 总线分层合并：Bsp 只留纯硬件驱动，节点注册 / 分发 / 发送调度 / 回退缓冲移到
      Service 层的 CanBus，并补充 Bus-Off 自动恢复（见 [CAN分层合并计划](CAN分层合并计划.md)）
- [x] 代码规范落地：分区横幅、命名、`Config` 构造模式、禁用 `friend`、全仓统一格式化
      基线（`User/`、`QSPI_Flash/`）

## 备注

- SPI 与 IIC 的 BSP 不打算写：顾虑在回调处理，目前工程里这两类通讯用的都是阻塞方式。这类通讯模式本身也最适合阻塞实现——都需要先建立连接再等待（如 CS 拉高拉低、IIC 的时序处理）。
- CAN 合并的实机回归（三路收发、节点回调、Bus-Off 恢复、回退缓冲溢出、Live Watch 读 `diagnostics`）尚未执行，清单见 [CAN分层合并计划](CAN分层合并计划.md)。
