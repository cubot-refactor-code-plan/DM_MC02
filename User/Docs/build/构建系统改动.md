# 构建系统改动

为接入 `User/` 库、浮点打印与两段镜像烧写，对根目录 `CMakeLists.txt` 与 `User/CMakeLists.txt` 所做的改动。每节先说明改动位置与目的，再给出代码；代码摘自根目录 `CMakeLists.txt`，未标注文件的均指该文件。

## 1. User 库接入

**位置**：主 `CMakeLists.txt` 末尾，用 `##### User #####` 标记。

**目的**：把 `User/` 作为子目录加入构建，并把 `User_lib` 链接进主目标。

```cmake
##### User #####

# Add User's folders to main
add_subdirectory(User)

# Add stm32cubemx to User_lib
target_link_libraries(User_lib PRIVATE stm32cubemx)

# Add User_lib to main
target_link_libraries(${CMAKE_PROJECT_NAME}
    User_lib
)
```

`User_lib` 在 `User/CMakeLists.txt` 中定义：用 `file(GLOB_RECURSE ... CONFIGURE_DEPENDS)` 收集 `User/**/*.{c,cpp}`，新增源文件无需修改构建脚本；头文件搜索路径覆盖 `Bsp` / `Device` / `Module` / `Algorithm` / `Service` / `Protocol` / `App`（其中 `Protocol` 当前为空）。

## 2. 浮点打印

**位置**：主 `CMakeLists.txt` 末尾。

**目的**：让 `printf` 支持 `%f` 等浮点格式；不加这一项时，浮点参数的打印结果不正确。

```cmake
target_link_options(${CMAKE_PROJECT_NAME} PRIVATE -u _printf_float)
```

## 3. 构建产物

编译完成后只产出 `DM_MC02.elf`（另有 CMake 导出的 `compile_commands.json`，供 clangd 做代码索引）。

内存段定义见 [链接脚本改动.md](链接脚本改动.md)。
