# Module 层

> 代码：`User/Module/`　只依赖 Device（及 Service 的纯工具）。
> 分层原则：[Docs/spec/分层架构.md](../../Docs/spec/分层架构.md)
> 方案记录：[Docs/plan/CoreXY模块层方案.md](../../Docs/plan/CoreXY模块层方案.md)

Module 把多个设备组合成一个有物理意义的机构：坐标、限位、分段规划、到位判定。
一个实例 = 一个机构；模块不建任务、不创建锁、不读串口（总线互斥借用设备组的递归锁）。
具体实例绑定的数值见 [`module_cfg.md`](module_cfg.md)。
