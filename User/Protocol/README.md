# Protocol 层

> 代码：`User/Protocol/`

本层只做编码 / 解析，不碰串口、不创建任务、不持有设备状态；单机与多机驱动共用同一套帧。

## 模块文档

| 模块 | 文档 | 内容 |
| --- | --- | --- |
| `emmv5_protocol` | [emmv5_protocol.md](emmv5_protocol.md) | `Frame`、命令帧与功能码、扫描器、MMCL、与 Device 的契约、新增命令 |

## 层规则

- 可放：语义参数 → 字节帧、字节流 → 应答、协议常量与查表。
- 不可放：发送帧、读串口、地址表、重发、超时、在线判定、任何 BSP / Device 头文件。
- **Device 不拼字节，Protocol 不发字节。**

## 与代码注释的分工

- 代码保留：工厂函数 `@brief`、参数单位 / 范围、单条帧布局。
- 文档覆盖：功能码总表、加速度公式、MMCL 布局、扫描器行为、新增步骤。
